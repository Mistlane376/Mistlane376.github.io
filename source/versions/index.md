## 🎯 版本历史

### v4.1.0 - 视觉统一与相册上线 (2026-07-27)

#### ✨ 重大更新

**相册系统正式上线**
- 新增独立相册页面 `/album/`
- 支持分组查看与封面预览
- 支持多张照片重叠展示
- 支持按日期自动分块浏览
- 支持灯箱预览、前后切换与缩略图导航
- 兼容本地图片、GitHub Raw 与 jsDelivr 图床

**首页文章列表重构**
- 首页布局改为更稳定的单列卡片结构
- 桌面端采用左图右文，移动端自动切换为上下排布
- 首页摘要优先使用 `description`
- 统一文章标题、日期、分类与摘要层级
- 优化六篇文章卡片的整体视觉节奏

**Markdown 正文阅读系统重构**
- 正文样式仅作用于文章详情页，不再干扰首页与功能页面
- 阅读区宽度调整为约 760px，统一段落节奏和标题层级
- 重做引用、列表、代码、表格、图片与提示框样式
- 完善暗色模式和手机端阅读体验

**导航与功能页整合**
- 导航新增“相册”入口
- 将“追番 / 友链 / 版本”收纳到“探索”分组
- 分类、标签、归档、关于、友链、追番等页面统一视觉风格
- 页面横幅与背景策略更简洁，整体更贴合当前站点气质

#### 🔧 体验优化

- 修复“探索”下拉菜单被页面内容遮挡的问题
- 优化相册页在手机端的统计栏与切换按钮显示
- 修复关于页标题、签名与分类数量徽章的裁切问题
- 补充暗色模式与减少动画偏好适配

#### 📝 文档

- 新增相册使用说明文档
- 补充 GitHub 图床接入说明
- 完善相册数据结构示例与分类组织方式
