# Mistlane Theme

This is the site's local presentation theme. It owns the Butterfly-derived
templates and the Mistlane visual system.

## Ownership

- `layout/`: page markup and shared components
- `source/css/`: base theme styles and Mistlane component styles
- `source/js/`: base theme behavior and Mistlane page interactions
- `_config.mistlane.yml` in the site root: active theme configuration

Site content, media, and data remain under the root `source/` directory.

## Validation

Run `npm run build` after theme changes. Check the home page, a post, archive,
about page, album, guestbook, and the mobile layout before deployment.

See `UPSTREAM.md` for the source baseline and license attribution.
