# Upstream Baseline

Mistlane is a local Hexo theme derived from `hexo-theme-butterfly` 5.6.1.

- Upstream repository: https://github.com/jerryc127/hexo-theme-butterfly
- Baseline package version: 5.6.1
- Imported on: 2026-08-11
- Upstream license: Apache-2.0, retained in `LICENSE`

This theme is intentionally maintained locally. Changes to its layouts, Stylus
sources, static assets, and scripts are versioned with this site. The
`source/css/mistlane` and `source/js/mistlane` directories contain the
Mistlane-specific visual and interaction layers.

When upstream code is consulted in the future, compare it against the 5.6.1
baseline before applying a selective change. Do not replace this directory with
an npm installation.
